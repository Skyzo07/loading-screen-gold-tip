One sharp, funny loading-screen tip for stressed developers and AI coding agents, 108 characters, one line:

> Tip: If your agent says 'done' and nothing works, it finished the task you described, not the one you meant.

Chosen by an independent judge panel from 18 candidates against the brief's criteria in order (on-subject tip, real laugh, lands in a glance, speaks to developer and agent at once, fresh). The tip is the prompt-misunderstanding both sides share: the developer described one task, the agent finished another.

## Run it

```sh
node main.ts
```

Writes the tip to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default). Deterministic, no network, no clock, no randomness; the program fails loudly if the line is not 1–200 characters or not a single unpadded line.
